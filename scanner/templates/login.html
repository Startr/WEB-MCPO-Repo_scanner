Available endpoints

TodoScope currently implements the Model Context Protocol (MCP). Any compatible client can discover and call these endpoints.

Endpoint Method Auth Purpose
GET No Service discovery
GET No OpenAPI 3.0 spec
POST Yes Scan a repo, return TODOs
POST Yes Stream TODOs (NDJSON)
GET Yes List registered repos
POST Yes Pull latest for a repo
